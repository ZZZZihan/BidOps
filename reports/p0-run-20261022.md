## 2. 实现架构与范围

| 层 | 实际实现 |
|---|---|
| 来源管理 | `config/sources.json`，官方主机注册、有限精确 URL 白名单、robots/terms 状态与审计说明 |
| CLI | `source inspect`、`import-urls`、`import-file`、`fetch`、`parse`、`export-manifest`、`import-bundle`、`stats`、`migrate` |
| 网络 | 默认关闭；执行开关、配置开关、权限证据和精确 URL 检查；串行至少 5 秒间隔；最多 3 次超时/暂时服务错误尝试；403/404/401/429 和重定向不重试、不绕过 |
| 存储 | 原始字节内容寻址、SHA256/大小校验、来源 URL 与 UTC 观察时间、HTTP 元数据；SQLAlchemy + SQLite 编号迁移及审计事件表 |
| 去重和历史 | URL + 字节哈希幂等，跨 URL 相同字节复用原始 blob 并保留各自来源；内容变化产生新记录；更正/终止/中标不覆盖旧版本 |
| 解析 | Python/Pydantic 确定性规则；项目编号/名称、采购单位、预算与原单位、公告日期、投标/文件截止、公告类型、中小企业原文、采购包与证据字符区间 |
| API | `GET /health`、`GET /sources`、带分页的 `GET /notices`、`GET /notices/{id}` |
| 前端 | React + TypeScript + Vite；公告列表、详情、原文链接、采购包、缺失状态、证据和完整性校验；初始页面真实为空 |
| CI | GitHub Actions：锁定依赖安装、Python lint/format/test、迁移和离线先导、前端 TypeScript 检查与构建 |

日期使用 Asia/Shanghai；日期精度不足时不补造时分。金额以 Decimal 精确换算，单位不明时保留 null。采购包金额不自动汇总为总预算。原文证据区间针对 `normalized_text_v1` 的 Unicode 字符位置，不是原始 HTML 字节偏移。资格条件仅保留原文，不作自动通过判断。

未使用 LLM API、模型训练、RAG、多 Agent、Harness、登录系统或付费云服务；未启动 P1 标注、P2 或比赛申报。详见 [实现边界](../docs/P0-IMPLEMENTATION.md)。
