# 本机真实 AI 问答 Demo

这个入口复用已经准备好的独立 Demo 数据目录，展示真实模型查询已导入公告、延续追问和核对原文证据。
它仅监听本机，不接入企业登录、企业画像、资格任务或人工审核流程。真实模型调用需要明确授权；本指南不代表已经完成真实调用验证。

## 启动前准备

从仓库根目录运行。需要已有 `.venv` 依赖、前端构建 `frontend/dist`，以及已经私有导入公告的 Demo 数据目录。
该目录应包含 `processed/bidops.sqlite3`、匹配的原始快照和该 Demo 自己的费用记录。
原始公告包需另行私有提供；仓库中的种子 URL 不会自动变成公告正文。

如尚未构建前端，在依赖已经安装后运行：

```bash
npm run build --prefix frontend
```

启动器 `scripts/live_demo.py` 不执行建库、迁移、公告导入或账本重置。数据库不存在或缺少前端构建时直接退出；预览不需要密钥，真实问答模式缺少密钥时会明确退出。
服务仍按原有启动流程执行幂等结构检查与数据回填，并在真实调用时保存新运行的用量记录，因此运行服务不是只读操作。
使用独立 Demo 副本，不要将历史原件或生产目录作为本入口的数据目录。

真实问答的凭证由服务端读取环境变量 `DEEPSEEK_API_KEY` 或本机忽略文件 `private/deepseek.env`。
密钥是否存在取决于当前机器与环境。使用前确认已获准复用相应密钥和新增调用预算，不要把密钥放入提问、截图或报告。

## 先预览，再开启真实问答

将下面的路径替换为已经准备好的目录；后续启动一直复用同一个路径：

```bash
bidops_demo_dir="/absolute/path/to/existing-bidops-demo"
.venv/bin/python scripts/live_demo.py --data-dir "$bidops_demo_dir"
```

默认只预览已保存的数据，不发起模型调用。打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)，先确认公告档案中有此次导入的六条公告和可查看的原文证据。

获得明确的真实调用授权后，先在原终端按 `Ctrl+C` 停止预览，再使用同一目录启动：

```bash
.venv/bin/python scripts/live_demo.py --data-dir "$bidops_demo_dir" --live --max-cost-cny 1
```

`--port 8765` 可显式指定端口；改用其他端口时，浏览器地址也要相应修改。
只有显式添加 `--live` 才开启真实问答。问答、欢迎页的示例问题按钮以及按 Enter 发送都会使用模型额度；看公告、查看已返回的证据不会再次调用模型。

## 两轮最短演示

先从公告档案确认 `TGPC-2026-A-0384` 已在此次导入的数据中，再进入“Agent 助手”：

1. 输入 **“TGPC-2026-A-0384 的预算是多少？”**，发送并等待回答完成。核对项目编号、预算卡片和右侧“原文证据”，展开预算引用查看原文和字符位置。
2. 保持在同一页面，输入 **“它的采购单位是谁？”**。确认回答仍指向同一项目，查看采购单位与对应证据，并展开“本轮调用记录”。

两轮之间不要刷新页面、切换工作区或点击“新对话”。若该项目不在此次导入的数据中，应使用公告档案中实际存在的完整项目编号。
核对结果以此次导入的原文与本次调用记录为准，不以旧报告的预期值代替。

两轮问题可能包含多次模型请求；工具查询与结构化输出会产生往返，实际次数以本次保存的用量记录为准。
如果调用超时、连接中断或返回错误，先保留错误与运行记录，确认状态和剩余授权后再决定是否重试；重复发送可能产生新费用。

## 重启与费用

停止服务后，在仓库根目录用相同的 `--data-dir` 重新启动；新终端中需重新设置 `bidops_demo_dir`。
只预览时用默认命令，继续获授权的真实问答时才加 `--live --max-cost-cny 1`。

1 元是**指定 Demo 目录账本的累计估算上限**，不是每次启动新增 1 元。已有完成运行的估算费用，以及活动或失败运行保留的预留，都会参与预算检查。
重启不清零账本、不释放未确认预留；也不要通过换一个空目录绕过上限。
这个估算与预留不能保证供应商账单不超过 1 元，最终费用仍需按供应商用量记录核对。
Demo 目录的记录也不代表完整历史账本或供应商账户余额。

本机问答会话仅保存在服务进程内，默认最多八轮，模型上下文保留最近两轮。
页面刷新、切换工作区或服务重启后，当前界面没有恢复这段会话的入口；已写入的费用记录仍保留。

所有回答均来自已保存的历史快照，未联网确认最新更正、终止、附件或实际投标资格。
可运行的两轮问答说明当前模型与证据查询链可用，不代表历史库已恢复、企业流程已验收或系统已经部署。
