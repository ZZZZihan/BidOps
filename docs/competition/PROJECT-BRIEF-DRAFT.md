# 报名项目简介（草稿，待根据官方模板调整）

项目名：**BidOps — 面向中小企业的智能招投标工作台**

赛道：AiCoding 硬核组 / AI 智能体开发。

项目简介：针对中小型设备与软件服务商查找政府采购机会、阅读招标公告和核对投标条件效率低的问题，BidOps 拟构建以真实公告为依据的智能招投标工作台。产品提供来源可追溯的公告检索、结构化字段提取、关键时间节点提示、企业条件与资格要求对照、人工审核及任务清单。AI 重点用于工具辅助开发及未来基于证据的业务处理。严格区分已经验证的公告事实、缺失文件与待人工确认的资格条件，不代理提交投标文件。

**项目阶段：立项与数据可行性核查；当前尚无完成的 MVP、付费客户或商业化收益。**
