# 本机完整业务流程 Demo

这个入口让你依次体验项目筛选、企业资格核对和人工复核，保留原来的真实 AI 问答和公告档案。它使用已经导入的真实公告，以及明确标注为虚构的示例企业和材料。示例资料不能证明任何现实企业具备投标资格。

## 启动

从仓库根目录安装项目已经锁定的依赖并构建页面：

```bash
uv sync --frozen
uv pip install --python .venv/bin/python --require-hashes \
  -r requirements/durable.lock -r requirements/attachments.lock
npm ci --prefix frontend
npm run build --prefix frontend
```

使用此前一直使用的独立 Demo 数据目录。目录应包含已解析公告、配套原始文件和既有费用账本；启动器不会创建空库、重新采集公告或清零费用。首次切换前应停止原 Demo，并备份这个目录，其中 SQLite 数据库应使用一致性备份，不能在写入期间直接复制数据库文件。

```bash
bidops_demo_dir="/absolute/path/to/existing-bidops-demo"
.venv/bin/python scripts/workflow_demo.py --data-dir "$bidops_demo_dir"
```

默认是页面及资料预览模式，不能运行新的模型核对。已有真实调用授权时，使用同一目录启动：

```bash
.venv/bin/python scripts/workflow_demo.py --data-dir "$bidops_demo_dir" \
  --live --max-cost-cny 1 --key-file /absolute/path/to/private/deepseek.env
```

密钥文件只供服务器读取，内容为 `DEEPSEEK_API_KEY=…`，保存在本机私有目录并限制访问权限。也可沿用环境变量或当前 checkout 下的 `private/deepseek.env`。不要在网页、提问或仓库中填写密钥。

打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。这个入口限定本机回环地址和单进程，不是公司单点登录或对外服务。需要另一个端口时使用 `--port`，并在浏览器使用对应的 `127.0.0.1` 地址。

## 按页面走一遍

1. 进入本机示例身份，打开“完整流程”，准备示例企业。页面显示虚构企业、所用材料和固定版本；再次准备会复用此前版本。
2. 输入关键词和预算范围，筛选项目。筛选只判断是否符合这些条件，不能作为资格结论。可先选择公告较短、只有一个采购包的项目，再逐步体验复杂项目。
3. 选择项目及采购包，点击资格核对。系统建立持久任务，使用本次固定的企业资料和公告版本；等待页面返回要求、证据、缺件和核对草案。进入页面、筛选、查看旧结果不会自动调用模型。
4. 将已完成的核对送入人工复核。逐项查看公告要求与企业材料，根据实际判断选择确认、驳回或要求补充材料，并填写自己的理由。页面没有默认批准；保存成功后才形成复核记录。
5. 查看决定历史并导出审核包。能否结束本次复核以服务端返回的可用操作为准。未解决的缺件、冲突和来源限制不会因为导出就消失。

刷新页面时，引导页通过保存的引用重新读取服务端结果。登录失效后，重新进入本机身份再继续；无需抄写批次、任务或复核编号。高级企业资料、持久任务和人工复核页面仍可用于查看更详细的信息。

## 费用与恢复

问答和资格核对共用原数据目录的 `agent_runs` 账本。`--max-cost-cny 1` 表示该账本累计估算上限，重启或换入口不会增加额度。已完成请求按记录的用量估算，失败或状态未确认的请求保留预留费用；这不是供应商余额或最终账单。

模型核对可能需要多次请求。出现预算不足、超时或输出未通过验证时，页面应保留真实状态；不要通过更换空数据目录或删除运行记录来继续。只有明确重新提交才会创建新任务，且仍须通过原有预算检查。

重启应使用同一个数据目录和相同代码版本。任务系统会核验代码、依赖和输入版本；更新代码后，旧结果可能仍可读，但未完成任务的恢复或进一步复核可能被拒绝。保留旧 checkout 和数据备份可帮助定位，不能通过修改版本记录绕过核验。

业务库、企业材料、本机身份状态和任务系统状态都属于同一个私有 Demo 数据目录。仅备份其中一张表不能恢复完整流程。示例初始化清单损坏或来源被撤销时，入口会明确报错，不能自动覆盖用户资料。

## 当前演示边界

公告来自此前保存的历史快照；最新更正、终止和完整招标附件仍需核实。页面应保留来源过期、附件缺失和未知状态。本机示例身份不代表真实企业登录验收，虚构企业资料也不代表真实企业资格。

这个入口复用现有业务服务和持久任务、人审记录。能否称为真实模型验证，必须以实际运行记录为依据；离线测试中的模型替身只证明工程流程。原云端历史数据库和完整历史费用账本的恢复仍是另一项未完成工作。
