# Frontend

React + TypeScript + Vite. `npm ci`, then `npm run dev`; backend defaults to port 8000.
`npm run build` performs TypeScript checking and a production bundle. The `/api` proxy
defaults to `http://127.0.0.1:8000`; local verification may set `BIDOPS_API_PROXY_TARGET`.
Actual notice list, bounded pagination, source links, unknown fields and evidence details.
No chat, authentication or fake demo records. See docs/UI-P0.md.
